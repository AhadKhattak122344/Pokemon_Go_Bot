# Knowledge Base

This directory summarizes working knowledge from tracked experiments and source
review. It does not replace the full evidence ledger in `experiments/` and never
turns proposals into verified results.

Read order before suggesting a fix:

1. `known_failures.md`
2. `verified_working.md`
3. `assumptions.md`
4. `deprecated.md`
5. `codex_memory/attempted_approaches.json`

Use `tools/validate_against_history.py` for a quick machine-readable check before
recommending a runtime, API level, root change, or Proxmox deployment path.
